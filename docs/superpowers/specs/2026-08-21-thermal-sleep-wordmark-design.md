# 首页热熔睡眠标题设计说明

## 目标

将首页 Hero 区的中文主标题升级为黑色 canvas 内的热熔 wordmark 视觉，同时保留现有白色/浅蓝官网基调、手机报告主视觉、按钮和数据卖点。黑色只作为标题视觉容器出现，不改变整个首页背景。

## 已确认的视觉方向

- 采用“黑底标题舱”方向。
- 整体页面背景保持现状的白色到浅蓝色氛围。
- 左侧标题区域使用一个响应式黑色 canvas，桌面端接近左栏宽度，避免做成过小的卡片。
- 热熔 wordmark 使用短英文全大写单词循环：`SLEEP`、`REST`、`HEALTH`。
- 中文标题“用一夜的数据 / 读懂你的睡眠与健康”保留，作为黑色区域内的主要语义信息。
- 右侧手机报告、漂浮数据卡片、下载/演示按钮保持原有布局和比例。

## 布局与比例

- 继续沿用现有 Hero 的双栏 grid，不改变右侧视觉占比。
- 黑色标题 canvas 在桌面端宽度约为左栏可用宽度的 90%，高度约 300–340px，圆角适中，内部留出足够呼吸空间。
- 英文 wordmark 作为视觉焦点，尺寸随 canvas 宽度和 viewport 缩放，但设置合理的最小值，不能缩成装饰性小字。
- 中文主标题使用较大的白色粗体，按两行排版，保持当前标题的阅读优先级；英文词作为动态品牌层，不能盖住中文语义。
- 在平板/移动端将 canvas 宽度设为容器全宽，高度按内容自然增长；不通过固定高度压缩中文标题，也不让英文词横向溢出。
- 断点下继续保留当前 Hero 的居中布局与按钮换行逻辑。

## 动画与渲染约束

- 使用一个模块级循环状态和定时器，多个组件实例共享同一个单词索引和切换时间。
- 单词切换间隔为 3000ms；热熔 reveal loop 为 4000ms，单词切换时将 reveal 重新从零开始，避免循环回卷造成黑闪。
- 每个单词的最后一个 column 在 862ms 点燃，330ms 后完成；剩余时间保持 settled wordmark。
- 颜色只来自一条固定 thermal ramp；不额外绘制 outline、glow 或 gradient。
- 模糊热场通过预渲染的多级 alpha 和逐像素 LUT 合成，支持沿横向 sweep 的各向异性模糊；接近清晰状态时直接绘制以保护字形边缘。
- 在 q 的最后阶段将 thermal image 平滑 crossfade 到灰白色的 raw glyph alpha，保留抗锯齿。
- `prefers-reduced-motion` 下只绘制 settled wordmark，不启动动画和定时器。

## 字体与测量

- 继续复用项目现有字体栈，优先使用已加载的 800-weight sans。
- canvas 使用 800x800 reference space，并按 `min(width, height) / 800` 缩放。
- 在字体加载完成后重新执行布局测量，确保不同英文词的宽度和居中位置稳定。
- wordmark 需要在宽度上限制于 canvas 的安全区，避免长词在窄屏上被裁切。

## 文件边界

- 在 `index.html` 的 Hero 标题节点中增加热熔 canvas 容器和保留中文标题的结构。
- 在 `css/index.css` 中增加标题 canvas 的尺寸、响应式布局、黑色视觉容器和无动画降级样式。
- 在 `js/index.js` 中增加热熔 wordmark 的绘制模块，仅由 Hero 标题初始化调用。
- 不调整与本需求无关的导航、手机 mockup、浮动卡片、按钮或其它 section。

## 验收标准

1. 首页整体背景仍是白色/浅蓝，不会出现全屏黑底。
2. 桌面端黑色标题区域比例协调，英文 wordmark 和中文标题均清晰可读，不显得过小或被拉伸。
3. `SLEEP`、`REST`、`HEALTH` 每 3 秒切换一次，切换时从热熔起点重新展开，无黑闪、无多个实例不同步。
4. 热熔颜色和边缘效果来自 thermal ramp 与模糊场，不出现独立描边、额外发光或渐变层。
5. 移动端标题区域不溢出，中文标题和按钮保持可用。
6. 开启 reduced motion 时显示稳定的最终 wordmark，不持续消耗动画循环。
7. 页面现有 Hero 右侧报告图和漂浮数据卡片的尺寸、位置关系不被破坏。
